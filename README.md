# db_deep_research_agent

AI-powered deep research agent built on Databricks. Researches topics thoroughly, synthesizes findings, and produces comprehensive reports.

## Stack

- **Platform:** Databricks
- **Language:** Python
- **Focus:** Deep research / RAG / agent workflows

## Setup

```bash
# Clone
git clone https://github.com/Data-drone/db_deep_research_agent.git
cd db_deep_research_agent

# Install dependencies
pip install -r requirements.txt
```
